# Product Review Project

React exercise containing a product review component.

## Project structure

- `src/components/ProductReview.jsx`
- `src/App.jsx`

## Getting started

Install Node.js and npm, then run:

```bash
git clone https://github.com/JAYANTI-THAKOR-941/Review-Project.git
cd Review-Project
npm install
npm run dev
```

Open the development URL displayed in the terminal.
